# Skyboy Project Brief & Guidelines

## 1. Core Development Brief
- Read and follow all specifications defined in `@skyboy-build-brief.md`.

## 2. UI/UX & Design Rules (Anti-AI Slop)
- Apply non-generic, high-craft UI/UX standards during frontend generation.
- Strictly incorporate principles from local design skill files:
  - Use hand-drawn interactive elements from `@drawably/`
  - Refer to design principles in `@taste-skill/`
  - Apply system design guidelines from `@awesome-design-md/`
  - Utilize custom plugins from `@claude-plugins/`

## 3. Workflow Rules
- Generate responsive, polished, human-crafted interfaces with deliberate typography, tight visual hierarchy, and cohesive component structure.
- Do not output generic, templated placeholder designs.
