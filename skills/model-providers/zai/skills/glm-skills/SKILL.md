# GLM Skills (Z.ai)

Use this skill when installing or authoring official Agent Skills for the GLM family of models from [zai-org/GLM-skills](https://github.com/zai-org/GLM-skills). The repository ships skills for OCR, vision, and multimodal workflows.

## When it applies

- Installing official GLM skills into an agent runtime
- Choosing the right OCR / vision / multimodal skill for a task
- Authoring new skills against the GLM skill conventions
- Understanding how GLM models discover and load skills
