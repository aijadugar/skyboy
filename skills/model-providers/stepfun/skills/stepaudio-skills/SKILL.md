# StepAudio Skills (StepFun)

Use this skill when installing or authoring audio Agent Skills from StepFun's official repository ([stepfun-ai/StepAudio-Skills](https://github.com/stepfun-ai/StepAudio-Skills)) — audio skills for the Claw agent platform.

## When it applies

- Installing StepFun's audio skills into an agent runtime
- Wiring speech/audio capabilities (transcription, TTS, audio understanding) through Claw
- Contributing new audio skills back to the upstream repository
