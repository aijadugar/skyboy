# Microsoft Project OAgents

Use this skill when exploring Microsoft's experimental AI agent framework. This is a research/experimental project for building AI agent systems.

⚠️ **Experimental Status**: This is an experimental/research project. APIs and features may change without notice. Not recommended for production use.

## When it applies

- Researching experimental AI agent frameworks
- Exploring novel agent architectures and patterns
- Contributing to Microsoft's experimental agent research
- Learning about cutting-edge agent concepts
