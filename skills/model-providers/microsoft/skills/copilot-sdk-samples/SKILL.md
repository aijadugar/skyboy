# Copilot SDK Samples

Use this skill when exploring sample applications for agents powered by the Copilot SDK and GitHub Agentic Workflow System. This collection showcases practical implementations and patterns.

## When it applies

- Exploring sample applications for Copilot SDK agents
- Learning patterns for GitHub Agentic Workflow System
- Finding examples for agent development with Copilot
- Understanding integration approaches with GitHub's workflow system
