# Microsoft agentrc

Use this skill when preparing repositories for AI development and coding agents. Provides tools and configurations to make repositories AI-ready for coding agents.

## When it applies

- Preparing repositories for AI coding agent integration
- Setting up repository configurations for AI development
- Implementing tools for AI-assisted development workflows
- Creating AI-ready repository structures and conventions

---

## Quick start

```bash
# Install the tools
npm install -g @microsoft/agentrc

# Prepare a repository
agentrc init

# Configure for AI agents
agentrc configure
```
