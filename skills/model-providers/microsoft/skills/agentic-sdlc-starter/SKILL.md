Use this skill when exploring reference architecture for spec-driven, AI-assisted development using GitHub Copilot, MCP (Model Context Protocol), and repository context engineering.

- Building spec-driven development workflows with AI assistance
- Implementing GitHub Copilot integration for development
- Using MCP (Model Context Protocol) for context engineering

- Creating reference architectures for AI-augmented SDLC
