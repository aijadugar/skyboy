# Spec to Agents

Use this skill when exploring multi-agent event-planning workflows using Microsoft Agent Framework, Semantic Kernel, and AutoGen patterns. This sample demonstrates how to combine multiple Microsoft agent frameworks for complex event planning.

## When it applies

- Building multi-agent event planning workflows
- Combining Microsoft Agent Framework with Semantic Kernel
- Integrating AutoGen patterns with Microsoft frameworks
- Learning orchestration across multiple agent frameworks
