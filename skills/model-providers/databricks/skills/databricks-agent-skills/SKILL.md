Use this skill when installing or authoring Agent Skills for Databricks from the official repository ([databricks/databricks-agent-skills](https://github.com/databricks/databricks-agent-skills)).

## When it applies

- Installing Databricks agent skills into an agent runtime
- Building agentic workflows on the Databricks Data Intelligence Platform
- Contributing skills back to the upstream repository
