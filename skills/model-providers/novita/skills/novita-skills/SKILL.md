# Novita Skills

Use this skill when installing or authoring agent skills from Novita's official skills repository ([novitalabs/novita-skills](https://github.com/novitalabs/novita-skills)). The repo hosts reusable `SKILL.md` skills for any agent ecosystem that supports skill-based workflows.

## When it applies

- Installing Novita skills into a skill-capable agent runtime
- Building on Novita AI services through skill-based workflows
- Authoring new skills against the repo's SKILL.md conventions
