# Agentic Tools (Meta)

Use this skill when working with Meta's agentic tools — the plugin and skills repository published by facebook ([facebook/agentic-tools](https://github.com/facebook/agentic-tools)) for use with coding agents.

## When it applies

- Wiring Meta's agent-facing tools into a coding agent workflow
- Discovering which skills the agentic-tools repo ships and how to install them
- Contributing tools or skills back to the upstream repository
