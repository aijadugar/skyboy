# MiniMax Skills

Use this skill when installing or authoring Agent Skills from the official MiniMax skills repository ([MiniMax-AI/skills](https://github.com/MiniMax-AI/skills)).

## When it applies

- Installing MiniMax's official skills into an agent runtime
- Discovering which skills the MiniMax-AI/skills repo ships and how to install them
- Contributing skills back to the upstream repository
