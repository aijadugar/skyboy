# Skyboy.in Design System

This file supplements the Vercel-inspired foundation generated by `npx getdesign@latest add vercel` in `DESIGN.md`. For Skyboy-branded values, this file takes precedence, especially colors, dark-mode surfaces, accent gradients, motion, and reusable utilities.

## Colors

- Background base: `#09090B`
- Background elevated/surface: `#0F0F12`
- Border subtle: `rgba(255,255,255,0.08)`
- Border hover: `rgba(255,255,255,0.16)`
- Text primary: `#FAFAFA`
- Text secondary: `#A1A1AA`
- Text muted: `#71717A`
- Accent gradient: electric blue `#3B82F6` / `#2563EB` through purple `#8B5CF6` to cyan `#22D3EE`
- Success/positive metric: `#34D399`
- Warning/regression: `#F87171`

## Typography

- Headlines: Geist Sans variable, tight tracking from `-0.02em` to `-0.04em`, weight `600-700`.
- Body: Geist Sans variable, weight `400`, text-secondary, line-height `1.6-1.7`.
- Code, terminal, and metrics: Geist Mono variable.
- Type scale: hero h1 `text-5xl md:text-7xl`, section h2 `text-3xl md:text-5xl`, body `text-base md:text-lg`, small `text-sm`.

## Spacing And Layout

- Max content width: `1200px`, centered, `px-6 md:px-8`.
- Section vertical rhythm: `py-24 md:py-32`.
- Use generous whitespace between elements.

## Surfaces

- Cards: `bg-white/[0.03] border border-white/[0.08] rounded-2xl backdrop-blur transition`.
- Hover cards move to `border-white/[0.16]`.
- Avoid heavy drop shadows. Prefer soft accent-gradient glow at low opacity behind key elements.

## Motion

Framer Motion belongs only in hydrated React islands.

- Scroll reveal: opacity `0 -> 1`, y `16 -> 0`, duration `0.5`, ease `[0.16, 1, 0.3, 1]`, `whileInView`, `viewport={{ once: true, margin: "-80px" }}`.
- Stagger grids/lists by `0.08s`.
- Hover cards: scale `1.01-1.02` plus border transition, `200ms`.
- No parallax gimmicks. Use no more than one animated background per viewport.
- Use `useReducedMotion` in islands to disable or shorten motion.

## Accessibility

- Use semantic landmarks: `nav`, `main`, `section`, `footer`.
- One `h1` per page.
- Keep visible focus states and style them with the accent colors.
- Text secondary and muted values are chosen for contrast against `#09090B`.
